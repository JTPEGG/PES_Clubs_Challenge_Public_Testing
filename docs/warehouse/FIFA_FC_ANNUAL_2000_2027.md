# FIFA / EA FC annual player-data source catalogue: 2000–2027

**Research date:** 19 October 2026. **Scope:** one game edition per year, not one actual calendar year of player form. These references identify hosted datasets, not authorised production ingestion or quality-verified season snapshots.

**Practical result:** **23/28 editions (2005–2027 inclusive) have a public hosted file identified** (22 single-edition GitHub files plus FIFA23 within a hosted multiyear legacy CSV). **FIFA 2004** has a reported Excel database extract in a community archive, but we have not downloaded and inspected it. **FIFA 2000–2003** have no verified standalone tabular player files; community archive formats need investigation.

## How we would ingest

- Each edition gets its **own immutable dataset ID and source edition date**. FIFA 05 corresponds to the 2004/05 football season; it must not be relabelled as 2005/06.
- The `lbenz730/fifa_model` archive has per-edition files from **2005 through 2020**, with FIFA Index IDs and key personal/football fields; these IDs should not automatically be treated as EA's modern player IDs.
- FIFA21/22 are separate public CSVs. FIFA23 source is a larger 2015–23 archive that needs filtering and deduplication; FC24–FC27 use independent file formats and snapshots.
- Different game releases and subsequent roster patches **must not be mixed**. Keep `source_date`, `patch_version` and player identity confidence.
- For **FIFA 2004**, first retrieve the community **XLSX extract** from [Soccer Gaming's historical FIFA database thread](https://soccergaming.com/forums/threads/fifa-dbs-since-fifa-98-download.6469756/), inspect schema/content, then map to our warehouse. A forum statement isn't proof the ZIP or Excel is still downloadable.
- For **FIFA 2000–2003**, investigate archival binaries or separately distributed text exports. Community descriptions say older `.dbi` is not presently extracted; do not promise coverage until decoded. Football-squad historical data could be a fallback **but are not game-native FIFA ratings**.
- No source CSV is incorporated into this public GitHub branch. Only URLs, schema metadata and import readiness are catalogued. Rights, quality, seasons and source access should be assessed before a permanent import.
