## Output contract

- `PES_V2_22_EDITION_CLUB_SQUAD_MAP.sqlite`: separate men-only player, squad, club and league data, including all 25 PES-style integer core ratings and four auxiliary fields per player, source club, identity, height, weight, foot and positional data when originally present. User-facing player/club/league rows do **not** carry gender fields.
- `PES_V2_ALL_EDITION_CLUBS.csv`: men-only club and league review data, squad counts and source reliability notes.
- `CLUB_SQUAD_MAPPING_MANIFEST.json`: counts for each selected edition, including original input rows, excluded source rows, included game-facing player rows, clubs, leagues, free agents and missing club/competition labels.
- `README.txt`: scope, free-agent and identity safeguards, and compatibility caveats.

All game-facing historical edition selectors and `club_squad()` read helpers use the filtered SQLite catalogue, not the original mixed-player archive.

## Strict filtering and source-quality rules

- An explicit source gender identifying women excludes that row. Teams or competitions explicitly labelled female are excluded even if the player's gender field is blank.
- Historical source records with no gender information are **not falsely marked as independently verified men**; older FIFA editions still use their existing historical game roster data unless there is explicit contrary source evidence. Do not infer a player's gender from name or appearance.
- Never invent team registrations, gender, date-specific league membership, transfer budgets, contracts, wages or PES game IDs.
- IDs are edition-and-source-row stable so the known 139 reused source player ID occurrences do not cause deletion or silent merging.
- Unknown club membership remains separate from genuine source-listed free agents.
- Source-supplied league and club ID references are used only within their annual edition and provider. Some historical sources have no credible league memberships; those are still flagged as unknown.
- FC25 remains unavailable and is excluded from all career dataset editions.
